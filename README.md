# FlowEdge AI Consultant landing page

A single-page, GitHub Pages-compatible website for FlowEdge AI Consultant and the 2-Week AI Audit.

## Publish on GitHub Pages

1. Create a GitHub repository named `ai-audit` under your GitHub account.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder.
3. Open the repository settings, find **Pages**, and choose the main branch and the root folder as the publishing source.
4. Your site will be available at `https://azrihanizai.github.io/ai-audit/` after GitHub finishes publishing it.

## Edit the placeholders

Open `index.html` to update the following items:

- The founding-client offer price in the highlighted offer banner: `[FREE / DISCOUNTED PRICE]`
- The number of founding-client spots: `[2]`
- The About section profile image placeholder and background text
- Any wording you would like to personalise

The booking, WhatsApp, email, and LinkedIn links are already connected to the provided contact details.

The site starts in light mode. Visitors can switch to dark mode using the theme button in the navigation, and their choice is remembered in that browser.
